# Support

For a debugging failure, collect:

1. VS Code, Windows and MASM/TASM versions; selected compiler/emulator. Python is not used in 0.4.
2. Output from “8086 Lab: Check Environment”. Remove personal paths before public posting if desired.
3. The smallest MASM/TASM 8086 source reproducing the problem, including required local INCLUDE files.
4. Debug Console build/errors and expected versus actual register values.

Do not include access tokens, credentials or unrelated workspace files. Once the GitHub repository is configured, report issues through its Issues page.
